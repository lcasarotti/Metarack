MetaRack Manual

MetaRack is a software modular synthesizer that is fully keyboard-accessible and screen-reader compatible (on Windows: NVDA, Jaws, Narrator). It is built on VCV Rack : every operation — adding modules, adjusting parameters, patching cables — is done without a mouse, with spoken feedback your screen reader can read.

This manual covers MetaRack's accessible interface. For details about individual modules, numeric expressions, and general modular-synthesis concepts, the online VCV Rack manual still applies; you can open it at any time with F1.

1. What MetaRack is

VCV Rack is a modular synthesizer emulator: you build instruments by virtually connecting modules (oscillators, filters, sequencers, mixers…) with cables, exactly as in a physical Eurorack system. Its original interface is purely graphical and therefore inaccessible to a screen reader.

MetaRack replaces that graphics with an interface made of native operating-system controls (lists, trees, a menu bar) that a screen reader can read and announce. The underlying audio engine is identical to VCV Rack: the same modules, the same sounds, the same patch files.

MetaRack shares VCV Rack's user folder, installed plugins, and online-library access; your patches stay compatible in both directions.

2. Starting and quitting

Starting the program

Launch MetaRack like any application (from the Start menu or its icon). On open, the "MetaRack" accessible window immediately receives the foreground and focus, and your screen reader announces its title. There is no separate graphical window to hunt for: the accessible interface is the program.

Quitting the program

To quit, use Ctrl+Q, or Alt+F4, or the File → Quit menu item. Your current work is saved automatically (autosave), as in VCV Rack: reopening brings you back to where you left off.

Only one instance can run at a time. If MetaRack is already open (or a "real" VCV Rack is, since they share the user folder), a second launch is refused to avoid corrupting the autosave.

3. The window's six views

The window shows one view at a time. Each view is a list (or a tree) you navigate with the arrow keys; you switch between them with the keys described below. At the bottom of the window a status bar reports short contextual messages (operation results, hints).

4. The Rack view: the module grid

In a modular synthesizer's rack, modules sit side by side on one or more rows. MetaRack faithfully reproduces this layout as a two-dimensional grid:

  • ← and → move through modules within the same row.
  • ↑ and ↓ jump between rows (when there is more than one).
  • You can also type a module's initial letter to jump to it (type-ahead search). The same works in the parameter and port lists: no shortcut takes up a plain letter any more.

For each item, the screen reader announces the module name followed by its position, in the form "— row N, slot M". The row is the line (starting at 1); the slot is the module's sequential position within that row (starting at 1). This numbering is meant for orientation; it does not correspond to physical HP units.

Free slots

Each row ends with a "[ Free slot ]" item: that is where you insert a new module. An empty rack contains a single free slot.

5. Adding modules from the Library

Press Shift+L to open the Library: a tree whose first level is the plugins (the brands) and whose second level is the individual modules each one offers.

KeyAction
↑ / ↓Move through the tree items.
→ / ← or Enter on a brandExpand or collapse the node to see its modules.
Enter on a modulePicks that model and returns to the Rack view. Then go to a [ Free slot ] and press Enter to insert it.

Full procedure to add a module:

  1. Shift+L to open the Library.
  2. Find the brand, expand it, scroll to the module you want.
  3. Enter on the module: you return to the Rack holding the model.
  4. Move to a free slot and press Enter: the module is inserted and focus stays on it.

6. Parameters, inputs and outputs

Every module has three separate lists, reached with F2 (Inputs), F3 (Outputs) and F4 (Parameters), or cycled with Tab / Shift+Tab. From the Rack view the three keys act on the focused module; once you are inside a module they jump straight from one list to another, without going back to the rack:

  • Parameters — knobs, sliders, switches and buttons. Each row shows the name and the current value.
  • Outputs — the module's output ports, with their state: "free" or the destination module they connect to.
  • Inputs — the input ports, with the same kind of state.

Scroll each list with ↑ and ↓. The screen reader announces each row's name and value (or state).

7. Adjusting parameters

In the Parameters view, on the focused parameter's row:

KeyAction
← / →Decrease / increase by a normal step (about 1% of the range).
Ctrl+← / Ctrl+→Fine step (one tenth of normal).
Shift+← / Shift+→Coarse step (four times normal).
Ctrl+Shift+← / →Ultra-fine step (one hundredth of normal).
BackspaceResets the parameter to its default value.
EnterOpens the "Set value" dialog to type an exact value.
SpaceFor latching switches: cycle the values. For momentary buttons (e.g. a sequencer's Run): one press = one trigger.
Application key or Shift+F10Opens the parameter's context menu ("Set value…" and "Reset to default").

The "Set value" dialog

Enter opens a dialog with a text field pre-filled with the current value. You can type a number or an expression (the same ones VCV Rack supports: note names, log2, dbtogain, vtof, and so on). Confirm with Enter (OK) or cancel with Esc.

Latching switches vs. momentary buttons. In VCV Rack, buttons come in two kinds. Latching switches hold their value (on/off, or several positions) and Space cycles through them. Momentary buttons (like a sequencer's Run) instead react to the moment of the press: MetaRack handles them by simulating a press-and-release, so a single Space equals a single trigger. For these, the resting value is always zero, so the "running" state does not appear in the cell — the feedback is audible only (the sound starts or stops).

8. Patching cables

Cables are created from the Outputs and Inputs views, in two steps:

  1. Go to a port (output or input) and press Enter: a connection begins. The status bar confirms it and you return to the Rack view.
  2. Navigate to the destination module, open its ports of the opposite type (if you started from an output, go to an input, and vice versa), and press Enter again on the chosen port: the cable is created. The screen reader announces "Connected: source module → destination module".

To cancel a connection you started but did not complete, press Esc.

Disconnecting cables

In the Outputs or Inputs view, on the focused port, press Del or Backspace: every cable on that port is disconnected (undoable with Ctrl+Z).

9. Multiple module selection

In the Rack view you can select several modules to act on them together.

KeyAction
SpaceAdds or removes the focused module from the selection. The screen reader announces "selected" / "N modules selected".
Shift+BackspaceQuickly clears the selection (deletes nothing).
DelDeletes all selected modules (with a "Delete N modules?" confirmation).
Ctrl+RRandomizes the parameters of the selected modules.

Selected modules stay marked in the list (the screen reader notes it as you scroll). The Edit menu also offers "Select all", "Deselect", and operations on the whole selection (Copy, Reset, Randomize, Disconnect, Bypass).

10. Module context menus

Every module offers extra commands through context menus. MetaRack exposes two distinct kinds.

Generic context menu

On the focused module (in the Rack view), press the Application key or Shift+F10. A list opens with the actions common to all modules: initialize, randomize, disconnect, bypass (toggle), duplicate (with and without cables), delete.

Module-specific context menu

Press F5, or Ctrl+Application key (from the Rack, Parameters, Outputs or Inputs views). This opens the list of options specific to that module — the same ones that, in the graphical interface, appear at the bottom of its context menu. For example, on a MIDI-to-CV you find: polyphony channel count, voice allocation mode, pitch-bend range, clock divider, MIDI reset (Panic), and so on. This is where you find everything a module's documentation describes that is not exposed as a parameter or a port.

Navigating context menus

KeyAction
↑ / ↓Move through the items.
EnterRuns the item. If the item has a submenu, enters it (a new level).
EscGoes back one level; at the top level, closes the menu and returns to the previous view.

Items that are active with a checkmark are announced as "selected".

11. Clickable displays (Shift+D)

Some modules have small text displays on their panel that, in the graphical interface, you click to choose an option: for example the audio device and sample rate on the Audio module, the device and channel on the MIDI modules, or the "learn" cell of the MIDI-CC module. These are neither parameters nor ports, so they do not appear in the usual lists.

From the Rack, Parameters, Outputs or Inputs view, press Shift+D to list the current module's clickable displays. From there:

  • Menu displays (e.g. choosing the audio device): Enter opens the list of options, you scroll with the arrows and choose one with Enter. Submenus are navigated like other context menus.
  • Learn displays (e.g. a MIDI-CC learn): Enter activates learn mode; move a control on your MIDI device to assign it, or use Space to toggle and Esc to cancel.

If the module has no clickable displays, the status bar says so.

12. Playing notes from the computer keyboard (Shift+K)

MetaRack can turn the computer keyboard into a small musical keyboard that sends MIDI notes, just like the original VCV Rack. Since the keyboard is normally used to navigate the interface, this feature is turned on and off with Shift+K: the screen reader announces "MIDI keyboard on" or "MIDI keyboard off".

Before you can play, you must tell a MIDI module to listen to the computer keyboard. For example add a MIDI-CV module, press Shift+D to open its clickable displays and choose the "Computer keyboard" device. Then patch the MIDI-CV's V/Oct (and Gate) output into an oscillator so you can hear the notes.

While the mode is on:

  • Keys that map to a note play, with the same layout as VCV Rack: the Z X C V… row is a piano keyboard (the white keys) and the row above, S D G…, the black keys; the Q W E… row repeats everything one octave higher.
  • The backtick (`) and 1 keys lower and raise the octave.
  • Navigation stays active: the arrows, Tab, Enter, Esc and every Ctrl or Shift shortcut keep driving the interface as usual. Only the keys that produce a note are "captured" by the synthesizer.

Because every navigation shortcut now lives on a function key or a combination, F2, F3, F4, F5 and Shift+D keep working while the MIDI keyboard is on. What you lose is type-ahead search in the lists: the letters play a note, so move around with the arrows or Tab, or turn the MIDI keyboard off with Shift+K. When you turn the mode off, any notes still held down are released, so no sound gets stuck.

13. The menu bar

At the top of the window there is a native menu bar, identical to VCV Rack's. You open it with Alt and navigate it with the arrows — the screen reader reads item names, submenus and checkmarks natively.

MenuMain contents
FileNew, Open, Open recent, Save, Save as, Save a copy, Revert, Overwrite template, Import selection, Quit.
EditUndo, Redo, Disconnect all cables, and the selection actions (Select all, Deselect, Copy, Reset, Randomize, Disconnect, Bypass).
ViewFullscreen, Zoom, Theme, Cable opacity and tension, Brightness, Knob mode, and various toggles (Tooltips, Lock cursor, Lock modules, etc.). Continuous settings are offered as submenus of preset values.

Interface language

MetaRack is available in English and Italian. The language follows the choice in Help → Language: English is the default, Italian is activated by selecting it (the change requires restarting the program).
